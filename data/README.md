# 数据来源和用途

## 实际使用数据

- `reference/6X18.pdb`：来自RCSB PDB 6X18，本次实际设计与界面参照文件。作者链P为GLP-1(7–36)，R为受体。原C端酰胺化在分子注释中，坐标未显式完整表达端基；肽Lys34 O占有率0，受体存在未解析段。分析排除非正占有率原子；未实际完成原子修复/质子化或膜处理，不声称完成这些步骤。
- `design/design.fasta`：用户实际保存的ColabDesign/ProteinMPNN32条采样，27A30Q、5WT。受体有坐标序列384 aa。Q23A和双突变是人工比较组合，不是原FASTA采样记录。
- `af3/*.zip`：12个真实AlphaFold Server任务，四组×三种子，每任务五模型，共60结构。原ZIP不改写，保留输入JSON、CIF、置信度、MSA和平台声明，用于研究复核。ZIP原始修改日期仅作文件来源参考，不能充当服务器调用时间。
- `esm/ESM_summary.csv`与`ESM_per_position.csv`：2026-10-03用户本地运行的四肽ESM-2真实推理输出。`run_metadata.json`保留当次环境和方法。A30Q单点分数另与2026-09-30记录一致，不把此事当作新的实验重复。
- `recorded/`：原Colab输出的60模型、种子汇总和四组摘要，为回归核对提供基准。记录用途是已知序列的计算复核，不是训练标签。

源文件SHA256和字节数在`input_manifest.json`；这是当前归档记录。历史下载日期没有完整记录则标记unknown，不伪造。

6X18 https://www.rcsb.org/structure/6X18 ，PDB DOI https://doi.org/10.2210/pdb6X18/pdb 。RCSB使用与引用要求 https://www.rcsb.org/pages/policies 。遵守数据库原始条款、正确引用结构和原研究，不重新授权数据库资料。

AlphaFold Server输出 https://alphafoldserver.com/output-terms 。原CIF开头保留平台使用声明；本包将其作为赛事学术核验材料，不标为自测实验结构。公共分享/商业用途需核查平台条款与团队知识产权安排。

没有纳入第三方受限临床数据、人类个体信息、API密钥或平台登录信息。没有将教学模拟细胞/动物表当作真实实验数据。Propedia和ChEMBL曾列入研究计划，但当前包没有声称使用这些数据库训练功能模型。

## 预处理与数据泄漏

序列精确去重；两位点四组合明确区分来源；按序列、种子、模型编号核对唯一性。CA、作者编号、token链编号先核对再计算；仅比较有共同坐标支持的参考接触。所有15预测样本都报告，代表结构以中位数邻近选择，不挑最高得分模型。

没有监督训练、微调或训练/验证/测试划分，没有独立测试集泛化结论，也未使用赛事隐藏评测集。上游模型预训练涉及公共序列或PDB数据，GLP家族和6X18可能重叠；关闭模板不能消除预训练记忆。模型训练数据名称/版本按上游说明披露，精确个体重叠不能完整核验。
